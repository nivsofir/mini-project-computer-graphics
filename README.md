# Procedural Cyberpunk City

A real-time, fully procedural 3D cyberpunk city built with [Three.js](https://threejs.org/) / WebGL for the Computer Graphics mini-project. Every building, texture, road, vehicle and light is generated by code at runtime from a single seed.

## Controls

| Input                                  | Effect                                                |
| -------------------------------------- | ----------------------------------------------------- |
| `SPACE`                                | Toggle cinematic (automatic) camera / free camera     |
| Mouse drag / wheel (free camera)       | Orbit / zoom                                          |
| **GENERATE NEW CITY** / **SEED** field | Regenerate the city, randomly or with a specific seed |
| Weather selector                       | Sunny / rain / storm / snow / blizzard                |
| Fog / Bloom / Camera Speed sliders     | Live-tune the atmosphere                              |
| FPS readout                            | Rolling average frame rate, top-left                  |

## Highlights

- Procedural buildings (multiple silhouette archetypes), roads, neon signage and textures — all generated from the seed
- Flying + ground traffic and pedestrians, weather system (rain, snow accumulation, lightning)
- Cinematic camera flying a Catmull-Rom spline with quaternion SLERP orientation
- Bloom + vignette post-processing, live neon reflections via a `CubeCamera` probe
- Optimized for low draw calls (merged geometry + instancing throughout)

## Troubleshooting: low FPS

If the FPS readout is stuck low, check `chrome://gpu` — if WebGL shows _"software only, hardware acceleration unavailable"_, enable **"Use graphics acceleration when available"** in `chrome://settings/system` and relaunch. No code change fixes software rendering; it's a browser/driver setting, not a scene-performance issue.
